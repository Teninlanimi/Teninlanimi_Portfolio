# Teninlanimi Faith Olajide — Portfolio

Personal portfolio of an ML engineer working on ranking, NLP and forecasting in Python.

**Live site:** https://teninlanimi-portfolio-e83w.vercel.app

## What's on it

- **Featured research:** content refresh prioritisation at FlyRank, with client-grouped evaluation and a [published paper](https://teninlanimi.github.io/flyrank-internship-ml/)
- **Projects:** fake news detection, Dangote Refinery IPO ROI model, academic outcome prediction, introvert vs extrovert classification and a stock price predictor
- **Experience, skills, education** and a downloadable resume

## Built with

Next.js (App Router), Tailwind CSS v4 and TypeScript, deployed on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000. Page content lives in `app/page.tsx`; the avatar and resume are in `public/`.
